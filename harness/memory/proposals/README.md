# 待批队列（proposals）

记忆写入分级（驾驭层设计 Step 4）里**推断类**的落点：

- 任务或对话产生的候选记忆，先经分类器判定：事实直入长期记忆；**推断进本队列**，不进长期记忆、不参与注入。
- 拿不准类别的一律归推断（宁可多问，不可错放）；li 说过不记的类别当场丢弃，不落任何文件。
- li 攒批处理本队列：批准 → 移入对应长期记忆文件并标 `li-approved`；驳回 → 删除，并留一条驳回记录给评估层校准分类器。
- 一条候选一个文件，文件名建议 `YYYYMMDD-<短题>.md`，正文写清陈述、依据、来源、产生任务的 run_id。

本阶段（阶段 2）只落机制与目录，不实现分类器与自动入队——那是评估层（阶段 4）的活。
